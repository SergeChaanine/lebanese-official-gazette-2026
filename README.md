# Lebanese Official Gazette 2026 — OCR Text

OCR text extracted from scanned pages of Lebanon's Official Gazette for 2026.
The text is saved in UTF-8 and preserved as transcribed.

Source: [Presidency of the Council of Ministers — Official Gazette](http://www.pcm.gov.lb/arabic/subpg.aspx?pageid=26725).

## Folder structure

```text
issue_001_2026-01-01/
  page_0001/
    content.txt
  page_0002/
    content.txt
issue_004_supplement_1_2026-01-22/
  page_0001/
    content.txt
```

Each issue has its own folder, and each transcribed scan has a page folder
containing one `content.txt` file. Page folder numbers represent scan order
within the issue, which may differ from printed gazette page numbers.

## Current coverage

Snapshot: **3 November 2026** — **9,153 transcribed pages** across
**44 issue folders** (37 regular issues and 7 supplements).

This is a partial collection covering regular issues 1–37 and their collected
supplements. Issue 37 contains 93 of its 222 discovered scans. Page discovery
was incomplete for issues 24 and 31. Issues 38–46 are not included yet.

## OCR quality

The text has not been manually corrected. OCR may misread Arabic words,
numbers, dates, amounts, and table reading order. Check important details
against the official source.
